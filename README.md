# NoteMap

This is a prototype built in JavaScript, which will be changed to Kotlin in Release 2.For this program to work, you will need a Google Maps API key with the Maps JavaScript API enabled and the Routes API enabled
Your key will need to be entered at the bottom of the index.html page, replacing the "ENTERKEYHERE"

This project will run with Node.js without requiring a build, so just load it up in your IDE and use "npm start" to launch the program

To properly simulate the user experience, you will need to open localhost on 2 seperate tabs and share the generated or entered pairing code between both tabs.
